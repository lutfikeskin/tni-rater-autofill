TNI answer key

What this is. Each row is a question these quotes met. Decide TNI's right answer once; the benchmark then scores today's rules against it every week (npm run benchmark -- --key). Every row starts with a proposal from today's rules or the agent's answer. A proposal is not a decision: nothing goes into the key until you confirm it. Changing an answer confirms it.

  • This answer: a TNI standard or another fixed answer (a standard can be limited to states).
  • The intake's answer at a record path (drivers[].dob is each driver's). A blank intake answer then counts as missing: the agent's.
  • The agent's: a client fact the intake doesn't give, or an attestation. Rules that fill it are counted as invented.
  • Not applicable: nobody should answer it here.
  • Depends on the client: decide it quote by quote in section C.

Work top to bottom: A (standards), then B (which intake field answers each question, and the values a rule works out), then C (this client's answers). "Confirm unconfirmed in this section" confirms what you leave as proposed, except rows where the agent and the rules disagree, which need their own decision. Your work is kept in this browser as you go; Save key.json to keep it (save it to layouts/answer-key/key.json). To continue later, open a new sheet (or this one) and load the saved key.

A. Standards

Questions today's rules answer with a TNI standard in at least one quote. One answer per question; limit it to states when TNI's standard holds only there. A quote where the intake answers it instead is listed in C.

B. Intake fields

Which intake field answers each question. The quotes' values are listed under each row: check them, then confirm. A question a rule works out from the intake (a band, a name split, a yes/no from an amount) is confirmed as its listed answers, quote by quote; if one is wrong, choose "Depends on the client" and correct it in C.

C. This client's answers

First the questions today's rules leave to the agent (one row each: is it always the client's, or is there an answer?), then one row per quote where the answer depends on that client: coverage choices, answers the agent changed, today's rules and the agent disagreeing, and quotes today's rules answer differently from their question's row.
