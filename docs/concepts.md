# Concepts: what each carrier question is about

Generated by `npm run concepts` from [src/concepts.js](../src/concepts.js) and every carrier rule's `concept`; do not edit by hand. Each row is a concept and where it is asked: the rule's question id (`q`, which logs and reviews use; Progressive has renumbered its pages' ids since, so it names the rule, not the page), then where the page shows it (its data-model field, selector, label pattern or question text). An empty cell: that carrier doesn't ask it. A change to a concept's answer touches every rule in its row; a new carrier question takes an existing concept when it means the same thing, else a new one in the catalog ([New carriers](new-carrier.md)).
